## Task 12 — embed + serve SPA + flip `spotdl web`
- New `spotdl_server/webui.py` `mount_webui(app)`: locates `webui/` via
  `importlib.resources`; when present serves it as a **root ASGI mount** with SPA
  fallback (real assets/files verbatim, any other non-`/api` GET → index.html);
  no-op when absent; called last in `create_app` in every mode.
  - Root ASGI mount, not a catch-all GET route, **on purpose**: a method-typed
    catch-all turned a POST to an unmounted `/api` path (hosted downloads) into a
    405. The mount carries no method constraint and returns the framework's exact
    `{"detail":"Not Found"}` 404 for `/api`/non-GET, so API behavior is identical
    with or without the UI embedded (verified against `test_hosted_has_no_downloads_endpoint`).
- Packaging: hatchling `artifacts = ["src/spotdl_server/webui/**"]` (force-include
  fails hard when the git-ignored dir is absent; `artifacts` is a no-op).
- Makefile: `web-build`, `web-embed`, `dist`. `.gitignore` ignores the embed dir.
- Flipped `apps/cli/.../commands/web.py`: dropped the stub; opens the browser at

## Concerns / notes for review
1. **Search → click-through is not a working path.** A search hit's `id` is a
   snapshot id, not a canonical entity id, so `EntityCard`'s `/tracks/{id}` link
   404s on the track page. This is pre-existing f10b behavior; the e2e reaches the
   track via the home resolve flow instead (the real, working path). Worth a
   follow-up: either resolve-on-navigate for search hits, or link search cards
   through `/resolve`.
2. **Design-system components that were never built.** f10a shipped EntityCard,
   ScoreGauge, VoteButtons, ProgressBar (+ Badge/Button/Input/etc.), but NOT
   `SettingsSection`/`DefinitionRow`/`SegmentedControl`/`Tabs`/`StatCard`/
   `DataTable`. Per instructions those routes keep their local atoms; their
   `// MERGE:` comments remain as honest TODO markers (I did not delete them,
   since the swap they describe is still pending a future design-system PR).
3. **`test_webui_packaged` touches the source tree.** It must write a marker
   `webui/index.html` into `apps/server/src/spotdl_server/webui/` to build the
   wheel (force-include maps the source path), restoring it after. The dir is
   git-ignored, so no repo impact, but the test is heavier than a unit test
   (hence the `packaging` marker).
4. **CollectionView** no longer uses the design-system EntityCard (inlined row),
   a deliberate call for uniform track lists; revisit if a dedicated
   design-system `TrackRow` lands.
