## Navigation model

Sections are Textual **modes** (one screen stack each): keys `1`–`5` →
Search/Queue/Settings/Account/Admin. Flagged sections (`queue`=can_download,
`auth`=can_auth, `admin`=is_admin) install only when the `SessionSnapshot` flag is
set; a gated key is a no-op (CONTRACT F — hidden, never a per-request error).
Entities push onto the current mode's stack; `escape` pops back. `?` pushes Help.
