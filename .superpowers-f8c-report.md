## Concerns / deviations (need integrator awareness)
1. **`DEFAULT_API_URL`**: the brief's Step 1 says assert `== "https://api.spotdl.org"`,
   but the binding in the teammate handoff (and the value already in `client.py`)
   is `"https://api.spotdl.dev"`. I followed the **binding** — test asserts `.dev`
   and that it is neither `localhost` nor `127.0.0.1`. The brief's `.org` is stale.
2. **Probe path**: CONTRACT C text says `GET /health`, but the server actually
   mounts it at `/api/v1/health` (`spotdl_server/api/routers/meta.py`). I probe the
   **real** route — a probe against a 404 path cannot distinguish "up" from "down".
   `HEALTH_PATH` in `fallback.py` documents this.
3. **`from_config` is not end-to-end runnable until Task 4** lands the embedded
   factory (or a caller passes `_embedded_factory`). The default factory raises a
   clear NotImplementedError pointing at Task 4. All my tests inject a fake, so the
   selection logic is fully covered in isolation.
4. **PAT from credentials** (`_load_credential_token`) depends on Task 3's
   `spotdl_cli.credentials.get_token`; resolved lazily, returns `None` when absent
   (anonymous). Origin key = `api_url` as-is; reconcile with Task 3's origin
   normalization if it differs.
5. Rule 5's `RemoteRequiredError` is the raise/exit contract; the **auth commands
   (Task 6)** must catch it and print `.message` + exit `.exit_code`.
