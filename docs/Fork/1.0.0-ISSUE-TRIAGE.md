## Confirmed and actionable issues

### #2702 — Not downloading singles
- Root cause: artist metadata collection and filtering are too strict for single releases when the upstream API does not return the expected groups consistently.
- Relevant code: `spotdl/types/artist.py`, `spotdl/utils/search.py`.
- Action: verify `include_groups` / legacy fallback behavior and keep the album-type filtering logic consistent across Spotify clients.

### #2680 — Web UI does not support playlist URLs
- Root cause: the UI resolves song URLs directly and does not pass playlist/album/artist URLs through the normal resolver flow.
- Relevant code: `spotdl/web/routes.py`, `spotdl/web/api.py`.
- Action: resolve the input type before download and route playlist URLs through the list-based path.

### #2556 — No M3U with --fetch-albums
- Root cause: album expansion adds songs without preserving the original list context, which breaks M3U generation.
- Relevant code: `spotdl/download/downloader.py`, `spotdl/utils/m3u.py`.
- Action: preserve the originating `list_name` during album expansion or generate the M3U from the original list before the expansion step.

### #2492 — Deleted track crashes the batch and prevents M3U generation
- Root cause: when a Spotify track is no longer available, item resolution fails early and prevents the rest of the list from being processed.
- Relevant code: `spotdl/utils/search.py`, `spotdl/download/downloader.py`.
- Action: wrap each unresolved item in a safe fallback and continue processing the rest of the batch.

### #2328 — --archive blocks M3U generation
- Root cause: archive filtering is applied before M3U assembly, so already-downloaded items are omitted from the generated playlist file.
- Relevant code: `spotdl/download/downloader.py`.
- Action: build the M3U from the original song set and filter only after the playlist file has been assembled.

### #2371 — --restrict=strict does not sanitize directories
- Root cause: path sanitization is applied only to the final filename segment, not to intermediate directory components.
- Relevant code: `spotdl/utils/formatter.py`.
- Action: sanitize each path segment when generating nested output directories and add coverage for directory traversal and unsafe characters.

### #2312 — --proxy rejects domain names
- Root cause: proxy validation accepts only IPv4 patterns and rejects valid hostnames such as `http://gluetun:8888`.
- Relevant code: `spotdl/download/downloader.py`.
- Action: validate the URL using `urllib.parse.urlparse` and allow hostnames and ports, not just numeric IP addresses.

### #2075 / #2467 — WebSocket race conditions and client-not-found errors
- Root cause: the client registry can be queried before the client is initialized, causing a race during early requests.
- Relevant code: `spotdl/web/api.py`, `spotdl/utils/web.py`.
- Action: lazily initialize missing clients and make the settings route resilient when the registration order changes.
