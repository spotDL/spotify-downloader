# Fork 1.0.0

Based on upstream spotDL 4.5.2.

## Added

- Interactive Textual TUI for menu, query, tracklist, confirm, download, lyrics, CLI-builder, and web-launch screens, with English and Spanish interface language support.
- Download form presets: Custom, Lightest, Efficient, Balanced, and Studio.
- Confirmation screen before download with the selected format, bitrate, audio provider, lyrics provider, threads, overwrite mode, and output directory, including a Modify action that keeps the current form state.
- Recent URL and recent download history in the main menu.
- 96 kbps bitrate option.
- Interactive first-run setup via `spotdl --setup` and non-interactive setup via `spotdl --setup <path>`.
- Setup access from inside the TUI menu without leaving the app.
- Auto-launch setup when required runtime tools are missing.
- Live language switching in setup screens.

## Changed

- Version footer styling was corrected so the footer remains visible without being clipped at the bottom of the TUI.
- Same-title tracks are no longer treated as duplicates when they come from different releases, live recordings, or stream/album variants.
- Artist deduplication now keys by title + album + artist instead of title alone.

## Fixed

- Removed the false duplicate collapse that skipped valid tracks like same-name songs from different albums or live versions.
- M3U playlist entries are now written with forward slashes and relative paths, improving compatibility with Apple Music and similar importers.
- The fork keeps the working-tree fixes needed for matching, metadata, M3U output, and provider behavior at the point of this release.
