# Fork 1.0.0

Based on upstream spotDL 4.5.2.

## Added

- Interactive Textual-based TUI (menu, query, tracklist, confirm,
  download, lyrics, CLI builder, web launcher screens) with English
  and Spanish interface language.
- Preset templates for the download form: Custom, Lightest, Efficient,
  Balanced, Studio. Lightest uses opus at 96k with lyrics saved as
  .lrc.
- Confirmation screen shown after selecting tracks and before
  downloading: plain-text summary of the selected format, bitrate,
  audio provider, lyrics provider, threads, overwrite mode and output
  directory, with a Modify button that returns to the form without
  losing the entered values.
- Recent URL and recent download history on the main menu screen,
  stored locally per user.
- 96k bitrate option.

## Fixed

- Matching, metadata, m3u and provider fixes carried over from the
  working tree at the time of this release.
