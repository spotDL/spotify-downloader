Tasks 1–3 test only against the fake, so this is not a blocker — but **the real façade voting must be wired in the Task 6 voting task** (POST vote → re-fetch/apply tallies → return a fresh `MatchView`).

2. **`OFFLINE_AUTH_MESSAGE` uses the CONTRACT A literal, not `fallback.py`'s copy.** CONTRACT A (authoritative-verbatim) and the Task-3 brief both quote the exact literal `sign-in needs the community server; it's unavailable offline`; `test_vm_auth` copy-locks it. I followed the CONTRACT/brief literal. **Please confirm** — if you want it aligned to `fallback.py`, it's a one-line change + test update.

3. **`stream()` protocol-mismatch handling is fake-shaped.** `stream()` inspects `WsHello` frames from the stream and yields one `failed` on a version mismatch — which works against the fake (it yields the hello frame). The **real** `SpotdlClient.progress()` consumes the hello and raises `UnsupportedProtocol` before yielding, and `stream()` can't catch that by name (CONTRACT I forbids importing the client). So with the real client a mismatch would propagate `UnsupportedProtocol` rather than a `Loadable.failed`. **Reconcile in Task 8** (queue screen): either have the real `progress()` yield the hello, or broaden `stream()`'s catch. `WS_PROTOCOL_VERSION` is duplicated as a literal in `queue.py` for the same import-guard reason (mirrors `client.py`).

4. **`StatsRow.tracks = 0`.** `AdminStatsResponse` exposes no canonical-track total, so `AdminViewModel._stats_row` reports 0 for `tracks`; `matcher_version` comes from the session. Noted in `admin.py`.

5. **`TrackRow.provider = ""`.** `TrackView` carries no provider (canonical tracks are provider-agnostic; provider lives on `MatchRow`). Noted in `mappers.py`.

6. **`allow_indirect_imports = True` on both new contracts.** `config.py` imports `client` (`DEFAULT_API_URL`), so `viewmodels -> config -> client` is an unavoidable indirect edge — mirrors the existing `no_cli_core` rationale.
